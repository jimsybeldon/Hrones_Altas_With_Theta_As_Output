# Global Configuration (Recommended for all your projects)

Run these commands in your terminal. They don't need to be run from inside a specific project directory.

Set your name: Replace "Your Name" with your actual name.

git config --global user.name "jimsybeldon"

Set your email: Replace the email with the one you use for GitHub.

git config --global user.email "<jimsybeldon@gmail.com>"

Verify Your Settings
To check that the configuration was applied correctly, you can run:

git config --list

You should see the user.name and user.email you just set in the output.
